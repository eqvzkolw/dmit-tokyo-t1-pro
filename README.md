## 三档线路差的是回国那一段路，硬件是同一套

DMIT 东京三档产品的硬件口径一致：AMD EPYC 处理器、KVM 虚拟化、企业级 SSD，每个套餐配 1 个 IPv4 和 IPv6，常见 Linux 发行版都能选。价格差全部落在网络上。

**Tier 1（TYO.T1）**走 NTT 骨干（AS2914），没有针对中国大陆的路由优化。这条线早期叫 Lite，后来叫 Standard Network，现在官网写作 Tier 1，是同一条国际线路的三次改名，不是三个产品。如果你在旧测评里看到“东京 Lite”，说的就是它。

三网走向大致是这样：移动走 CMI 进国内，延迟通常控制在 60ms 以内，是这条线里体验最好的一档；电信走 NTT 直连，高峰期丢包偏多，延迟也不稳；联通的走向有两种说法，一说走 AS4837，一说同样走 NTT。具体走哪条不必纠结，按“没有大陆优化”来理解就够。

**Premium（TYO.Pro）**的回程三网走 CN2 GIA，去程电信和联通走优质路由、移动走 CMI。电信延迟约 60–65ms，联通和移动在 50–55ms，晚高峰不降速，丢包控制得比较低。DMIT 东京真正卖溢价的地方就在这里。

**Eyeball（TYO.EB）**原本是三网 CMI 回程的中间档，价格比 Pro 低一档，目前处于下架或缺货状态。官网看不到就不用找了，要么加钱上 Pro，要么省钱买 T1，中间那个选项暂时不存在。

## 流量超了之后，两条线的处理方式不一样

这是很多人买完才发现的问题。

T1 流量用完后不停机，限速继续跑。限速值有 50Mbps 和 50–100Mbps 两种说法，具体数字看官网，但“不停机、降速续用”这个机制是确定的。对个人轻量使用来说，基本触不到这个上限；真触到了也不至于业务中断。

Pro 流量超出后是暂停服务，不降速，要续费或者加购流量才恢复。跑正经业务的用户要提前算好月流量，别等到月中停摆。

这一条对选择的影响比配置更大。如果你的流量消耗波动大、又不想盯着用量看，T1 的容错空间明显更宽。

## 谁适合买 T1，谁买了会后悔

**T1 适合这三种人：**

1. 需要日本本地 IP，做日区内容、日区账号或日本用户能访问的服务
2. 网站或 API 面向日本、东南亚，对国内访问延迟不敏感
3. 预算有限，想用最低成本先占一台日本机器试业务

**T1 不适合的：**

- 主要用途是从国内 SSH 进去开发，电信用户高峰期会有明显卡顿
- 面向国内用户的网站，需要低延迟
- 对稳定性要求高，并且用电信宽带

这不是 T1 这一条线的问题，是所有不带大陆优化的国际线路的通病。T1 的定价逻辑就是“你需要日本 IP，但不需要回国速度”，接受这个前提再买。

反过来，Pro 不适合的是预算敏感又没有国内访问需求的用户。纯海外业务买 Pro，等于为一段永远用不上的线路付钱。

## 常被问到的几个问题

**T1 和以前的 Lite、Standard 是同一条线吗？**
是。Lite 改名为 Standard Network，后来又改成 Tier 1，线路没变，还是那条不带大陆优化的国际线路。

**东京 Pro 和香港 Pro 怎么比？**
香港 Premium 延迟更低，物理距离近，大约 20–50ms，但入门 TINY 要 $39.9/月。东京 Pro TINY 是 $21.9/月，线路质量接近，延迟略高一点。预算有限又想要 CN2 GIA 体验，东京是更便宜的入口。具体价格以官网为准。

**T1 的移动用户体验真的更好吗？**
移动走 CMI 回国，延迟基本在 60ms 以内，丢包不明显，是三网里最稳的。电信走 NTT，高峰期丢包偏多，不建议电信用户把 T1 当主力节点。

**先买小配置能升级吗？**
DMIT 支持套餐升级。先买 TINY 或 WEE 跑一段时间，确认业务量再往上换，比一上来买 MINI 以上合理。
